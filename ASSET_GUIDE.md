# ENDLESS BELOW — Asset Guide

This document is the production brief for every visual slot on the site.

Until a slot’s file exists, the site draws a **styled placeholder** that prints the slot name and the required source size. Dropping a real file in the path below and pointing the matching `src` field at it (in HTML or in `data/*.js`) is enough — layout, cropping and pixel scaling are already in CSS.

Do **not** permanently upscale pixel-art sources. CSS displays them at integer multiples with `image-rendering: pixelated`.

---

## How to deliver

| Kind | Format | Notes |
|---|---|---|
| Key art, environments, screenshots, portraits | WebP (quality 80–90) plus a PNG master | sRGB, no embedded colour profile surprises |
| Character full art that must sit on a dark panel | PNG or lossless WebP, **transparency optional** | If the background is painted, skip transparency |
| Pixel sprites | Indexed PNG, transparent | 16×16 source, nearest-neighbour only |
| Idle animation | Animated WebP (preferred), APNG, or GIF | Lossless, hard pixel edges. GIF is the compatibility fallback |
| Logo | SVG + transparent PNG | SVG is the live asset |
| Favicon | PNG | 512×512 master; we derive the rest |

File names are lowercase kebab-case. Do not put spaces in paths.

## Branding

### Logo — wordmark + sigil

| | |
|---|---|

| **Page / section** | Header lockup, footer, 404, future press kit |

## Classes

Each class lives in `assets/characters/<id>/` where `<id>` is the slug from `data/classes.js` (`archer`, `warrior`, `bard`, `priest`, `mage`, `rogue`, `paladin`, `barbarian`, `warlock`, `spellblade`).

Adding a class later: add a folder with the four files below, then append one object in `data/classes.js`. No HTML edits.

### Full art

| | |
|---|---|
| **Asset name** | `full-art` |
| **Page / section** | Classes page, detail modal (left column) |
| **Source resolution** | **1200×1600** |
| **Aspect ratio** | 3:4 |
| **Format** | Transparent PNG, or WebP if the background is painted |
| **Transparency** | Preferred, so the character sits on the site’s dark panel |
| **Safe area** | Entire silhouette inside the frame with **≥8% margin** on all sides. No cropped heels, bows, or weapon tips |
| **Mobile crop** | Modal stacks art above copy. 3:4 is shown in full. Do not rely on a wide cinematic crop |
| **Path** | `assets/characters/<id>/full-art.webp` |

### Portrait / card image

### Pixel sprite (static)

| | |
|---|---|
| **Asset name** | `sprite` |
| **Page / section** | Fallback if no idle animation is supplied |
| **Source resolution** | **16×16** |
| **Aspect ratio** | 1:1 |
| **Format** | PNG, transparent background |
| **Transparency** | Yes, hard binary alpha (no hair anti-alias) |
| **Safe area** | 1px transparent padding around the silhouette so scale-up does not clip |
| **Mobile crop** | Displayed at 64 / 96 / 128 CSS px (4× / 6× / 8×). Never non-integer |
| **Path** | `assets/characters/<id>/sprite.png` |

**Do not upscale this file.** The site scales it in CSS.

Placeholder 16×16 sprites (silhouette + class accent) are generated by `tools/generate-placeholders.ps1`. Replace them.

### Idle animation — side facing

Preferred delivery: a **single animated file**. Swap the path in data; the renderer emits `<img class="pixel-art">`.

| | |
|---|---|
| **Asset name** | `idle-side` |
| **Page / section** | Class cards (64px) and detail modal (96px) |
| **Source resolution** | **16×16 per frame** |
| **Aspect ratio** | 1:1 per frame |
| **Format** | Animated WebP (lossless) preferred; APNG; GIF as fallback |
| **Transparency** | Yes |
| **Safe area** | Same 1px padding as the static sprite. Pivot / feet stay consistent across frames |
| **Mobile crop** | None — sprite is never cropped |
| **Path** | `assets/characters/<id>/idle-side.webp` |
| **Data field** | `art.idle.animated` |

Alternative delivery: **horizontal spritesheet** (already wired).

| | |
|---|---|
| **Asset name** | `idle-side-sheet` |
| **Frame width** | 16 px |
| **Frame height** | 16 px |
| **Frame count** | 4 (adjust `art.idle.frames` if different) |
| **Direction** | Left → right |
| **Frame order** | 1 rest, 2 bob down, 3 rest, 4 bob up — a two-pixel idle breath |
| **Playback** | 6 fps (`art.idle.fps`) |
| **Facing** | Side (`art.idle.direction`) |
| **Path** | `assets/characters/<id>/idle-side-sheet.png` |
| **Data field** | `art.idle.sheet` |

Placeholder sheets are generated. When a real `idle-side.webp` is ready, set `animated` and leave `sheet` as fallback.

## Media page

Every gallery item is a slot in `data/media.js`. Replace `src: null` with a path.

| Category | Typical size | Ratio | Format | Notes |
|---|---|---|---|---|
| Screenshots | **1920×1080** (native game res) | 16:9 | PNG or high-quality WebP | Do not letterbox. Do not add chrome |
| Concept art | 1920×1080 or 1200×900 | 16:9 or 4:3 | WebP | Match the slot’s `ratio` field |
| Characters | 1200×1600 | 3:4 | PNG/WebP | Same as class full art |
| World | 1920×1080 | 16:9 | WebP | |
| Pixel art lineup | Native pixel size | — | PNG | Set `pixelArt: true` so the lightbox does not smooth it |
| Animations | 16×16 (sprite) or 1280×720 (gameplay capture) | 1:1 or 16:9 | Animated WebP | |
| Video (later) | 1920×1080 | 16:9 | MP4 (H.264) + WebM | Poster frame still required. Not wired yet |

Lightbox opens whatever `src` points at. Keep masters; the site does not generate srcset yet. When file size becomes a problem, add a 1280-wide WebP sibling and a `srcset` on the item.

## Pixel-art display contract

This is a hard rule for every sprite and pixel illustration on the site.

1. Author at native size (usually 16×16).
2. Export PNG with nearest-neighbour, no anti-alias, no colour bleed.
3. Do not pre-scale for “retina”.
4. The CSS class `.pixel-art` applies:

   ```css
   image-rendering: pixelated;
   image-rendering: crisp-edges;
   ```

5. Display sizes in use (all integer multiples of 16):

   | Token | CSS size | Scale |
   |---|---|---|
   | `--px-size-sm` | 64×64 | 4× |
   | `--px-size-md` | 96×96 | 6× |
   | `--px-size-lg` | 128×128 | 8× |
   | `--px-size-xl` | 160×160 | 10× |
   | `--px-size-2xl` | 192×192 | 12× |

## Colour & type (for painted work)

Match the site, do not fight it.

- Ground: `#050506`–`#16191f`
- Parchment: `#e6dcc6` / `#cdc0a4`
- Magic accents, used sparingly: violet `#6f5fb8`, cyan `#6fb3c0`
- No neon, no saturated primary red, no chrome-steel sci-fi

Display type on the site is Cinzel. If a painting includes the title, prefer a similar inscriptional serif, or leave the title off and let the site set it.

## Checklist for a new class

1. Create `assets/characters/<id>/`.
2. Drop in `sprite.png` (16×16), `idle-side.webp` (or sheet), `portrait.webp` (800×1000), `full-art.webp` (1200×1600).
3. Append an object to `data/classes.js` with those paths in `art.*.src` / `art.idle.animated`.
4. Reload. No HTML change.

## Checklist for a new devlog entry

1. Add `assets/media/devlog/<slug>.webp` at 1600×900.
2. Prepend an object to `data/devlog.js`. Set `mock: false` only for real history.
3. Reload.

## Checklist for a new patch

1. Optional banner: `assets/media/patch/<anchor>.webp` at 1600×600.
2. Prepend an object to `data/patch-notes.js` with a stable `anchor` (`v1-2-0` → `#v1-2-0`).
3. Set `mock: false` for a real release.
4. Reload.
